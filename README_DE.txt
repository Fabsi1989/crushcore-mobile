CRUSHCORE MOBILE - ANDROID PROJEKT

Dieses Projekt kann ohne Mac auf Windows entwickelt werden. Die APK wird mit GitHub Actions in der Cloud gebaut.


SCHNELLSTART:
1. ZIP entpacken.
2. Den Ordner CRUSHCORE_ANDROID_PROJECT in ein neues GitHub-Repository hochladen (oder mit GitHub Desktop committen/pushen).
3. Repository auf GitHub öffnen -> Actions.
4. Workflow "Build CRUSHCORE Android APK" auswählen.
5. "Run workflow" drücken.
6. Nach erfolgreichem Lauf den Workflow öffnen und unter Artifacts "CRUSHCORE-MOBILE-APK" herunterladen.
7. app-debug.apk aufs Android-Handy kopieren und installieren. Falls Android fragt, Installation aus dieser Quelle erlauben.


Hinweis: Dieses ZIP enthält den App-Projektstand und einen Cloud-Build-Workflow, nicht bereits eine fertige APK. Der APK-Build erfolgt über GitHub Actions.
